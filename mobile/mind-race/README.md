dossier tel quel sur l'hébergement.

| `cgu.html` | conditions d'utilisation | …/mind-race/cgu.html |
| `styles.css` | styles des trois pages (changer `?v=` dans les pages après une modification) | |
| `img/` | icône (256 px), captures d'écran (WebP) | |
| `icon.png` | icône 1024 px (fiches des stores) | |
| `../app-ads.txt` | fichier AdMob, à la racine du domaine | https://optisoftw.com/app-ads.txt |
